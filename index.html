📜 SF Editor Changelog

v1.2.0 23 Juni 2026

Perbaikan Kompatibilitas Dojo & Level Editor

  • Fix Dojo Save Crash: Memperbaiki bug yang memicu FormatException di game Self Defense Dojo dengan mempertahankan format JSON standar (kutipan kunci seperti "51" di dictionary tetap dipertahankan).
  • Tipe Data Coin & Exp: Menyelaraskan penyimpanan variabel coin dan exp agar dibungkus objek class {"i": nilai}, sementara fish_coin disimpan sebagai integer biasa.
  • Level Editor Custom: Menambahkan opsi langsung dari tim pengembang untuk menyunting Strength Level (power) ke 15 dan Skill Level ke 16 dengan satu klik/pembaruan data save yang presisi.
v1.1.0 22 Juni 2026

Rilis Awal SF Editor (Premium Theme & Day/Night Mode)

  • Tema Premium Alley Night: Menggunakan background jalan malam Jepang yang estetik dengan sentuhan visual glassmorphism transparan (blur 20px).
  • Day/Night Theme Toggle: Menambahkan tombol melayang (🌙 / ☀️) di pojok kanan atas untuk berpindah dari mode malam cyberpunk ke mode siang yang ramah mata secara instan.
  • Auto-Detect Format & Game: Pengguna tidak perlu memilih jenis file save di awal. Sistem otomatis membedakan format .es3 (Yakuza Rogue) dan .rpgsave (RPG Maker) serta mendeteksi gamenya secara cerdas.
  • Instagram Request Banner: Banner khusus untuk meminta penambahan game baru langsung terhubung ke profil Instagram pengembang.
  • Profil Pembuat Terintegrasi: Menambahkan avatar anime custom dan credit nama penulis "Dibuat dengan cinta oleh Vann sepulang kerja".
